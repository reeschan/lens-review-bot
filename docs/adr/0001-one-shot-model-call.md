# bot はモデルを道具なしで 1 回だけ呼ぶ

bot は、モデルに道具を持たせず、Messages API を 1 回だけ呼ぶ。材料を集めて束ねるのも、返った指摘を絞り込み、重複を除き、投稿するのも、bot のスクリプトが受け持つ。観点の文書は、回すたびに claude-plugins-official の既定ブランチから取ってきて、束ねに入れる。

手元で人が呼ぶ lens-review は、道具を使って自分で材料を集める作りのまま残す。

こう決めた理由は 2 つある。

- 費用は、おおむね「1 ターンで読む量 × ターン数」で決まる。claude-code-action の中で lens-review を回したときは、1 回のレビューに 13 ターンかかり、その大半が集める・書く・投稿するのに使われていた。
- seam 3 では、道具の許可の設計 (許す一覧、`Write` の規則、サンドボックスに要る socat) で何度も詰まった。

手元のほうは push のたびに回るわけではない。そのため、ファイルを読み回って裏を取れる利点のほうが、費用より大きい。

## Considered Options

- **claude-code-action のまま `--max-turns 1` にする**: 今の仕組みを使い回せる。ただ、Claude Code の土台の分 (約 1 万トークン) と、道具の許可の設定は残る。
- **道具を Read・Grep に絞った 2 回目の呼び出しで裏を取る**: 最初の版では入れない。モデルが指摘に付けた根拠の引用を、スクリプトが束ねと突き合わせて確かめることで代える。

## Consequences

- 観点の文書は、lens-review と bot の両方が使う。観点の書き方を変えるときは、道具なしでも読める書き方を保つ。
